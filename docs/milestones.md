# Milestones

1. **Detection preview:** RTSP input, local browser preview, YOLOX person detection, confidence and detection rate controls, optional DirectML. Benchmark alongside OBS on the target machine.
2. **Presenter selection:** choose and retain a target; evaluate multiple people, occlusion, poor lighting and loss of target.
3. **Simulation:** calculate smooth pan, tilt and zoom recommendations and test with a virtual camera. Stop on missing or stale input.
4. **Camera integration:** design a bounded, opt-in control adapter with manual override and a clear emergency stop; bench-test away from a live service.
5. **Rehearsal:** test operation, stream performance and rollback with an operator before any live use.
